# Pixel Suite 3.0.4

A fix for Play Integrity.

## 🐞 Bug fixes

- **Play Integrity:** Pixel Suite no longer uses Google Play services. It was only used for the soft scrolling edges on a few Google screens opened from Settings (Frosted Glass), and keeping it could cost you Device and Strong integrity, so it wasn't worth it. If you had it ticked in Pixel Suite's LSPosed scope, Pixel Suite now unticks it for you. Just reboot when it asks. Thanks to Ashray V K on Telegram for pointing it out 🙏

## Install

1. Install **PixelSuite-v3.0.4.apk** over your current version.
2. Reboot.
