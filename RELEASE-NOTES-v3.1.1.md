# Pixel Suite 3.1.1

**Turn off system-wide ad blocking**, use Hide search bar on more launchers, see longer names on Chrome's speed dial, and get a few fixes.

---

## ✨ Highlights

- 🛡️ **Block ads in every app** can now be turned off (Patreon)
- ⭐ **Longer names** on Chrome's speed dial (Patreon)
- 🔢 **Your PIN after a restart** no longer turns the screen off
- 🧹 **Hide search bar** on older Pixel Launcher versions

---

## 💎 Patreon

- 🛡️ **Block ads in every app**: turn it off to block ads only in Chrome and Google News. Your phone's hosts file goes back to stock right away, and removing the ad blocker module in your root manager now turns it off too.
- ⭐ **Speed dial**: website and folder names now use their whole column, so long names show much more before the "…".

*In Patreon › Google apps, and Chrome's new tab page.*

---

## 🪄 Polish

- 🗂️ **App drawer**: a folder or app you drop back in its own spot now lands with the same little rattle as a move.

---

## 🐞 Bug fixes

- 🔢 **Lock screen**: typing your PIN after a restart could turn the screen off. It stays on now.
- 🧹 **Hide search bar**: older Pixel Launcher versions said it isn't supported. It works there now.
- 🧭 **Navigation buttons**: an attempt to fix a second pair of buttons showing at the top of the screen on some phones.
- 📁 **Speed dial**: long folder names lost their first letters. They show from the start now.

---

## 📥 Install

1. Install **PixelSuite-v3.1.1.apk** over your current version.
2. Reboot (the Reboot pill in Pixel Suite does it for you).
