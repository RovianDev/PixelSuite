# Pixel Suite 3.0.1

A quick fix for the share menu.

## 🐞 Bug fixes

- **Share menu:** pinning an app no longer pushes the suggested apps out of the top row. Your pinned apps come first, and the suggestions fill the rest.

## Install

1. Install **PixelSuite-v3.0.1.apk** over your current version.
2. Reboot.

New in 3.0.0? See the [3.0.0 release notes](RELEASE-NOTES-v3.0.0.md) for everything that came with it.
